## ▶️ Cara Menjalankan Notebook

### Menggunakan Google Colab (Direkomendasikan)

1. Klik link notebook pada tabel pertemuan.
2. Pilih **Open in Colab**.
3. Jalankan seluruh sel menggunakan menu:

```
Runtime → Run All
```

4. Pastikan seluruh output muncul tanpa error.

### Menjalankan Secara Lokal

1. Install Python 3.x.
2. Install Jupyter Notebook atau JupyterLab.
3. Clone repository:

```bash
git clone https://github.com/username/nama-repository.git
```

4. Install library yang dibutuhkan:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy missingno requests
```

5. Jalankan Jupyter Notebook:

```bash
jupyter notebook
```

6. Buka file `.ipynb` yang ingin dijalankan.
