Repository ini merupakan dokumentasi sekaligus portofolio pembelajaran selama mengikuti mata kuliah **Pengantar Data Science**.

Seluruh notebook pada repository ini disusun berdasarkan aktivitas hands-on dan praktikum dari setiap pertemuan. #  Menjalankan Notebook

## Menggunakan Google Colab

1. Pilih notebook yang ingin dijalankan.
2. Klik **Open in Colab**.
3. Jalankan seluruh sel menggunakan menu:

```
Runtime → Run All
```

4. Pastikan seluruh output berhasil ditampilkan tanpa error.

---

## Menjalankan Secara Lokal

Clone repository

```bash
git clone https://github.com/rally-adty/UNSIA-Data-Sciense-SM-4.git
```

Masuk ke folder repository

```bash
cd UNSIA-Data-Sciense-SM-4
```

```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy missingno requests tensorflow mlxtend
```


# Kesimpulan Umum

Selama mengikuti pembelajaran Pengantar Data Science dari Pertemuan 1 hingga Pertemuan 13, saya memperoleh pemahaman mengenai tahapan utama dalam proses Data Science, mulai dari pengumpulan dan persiapan data, eksplorasi data, visualisasi, preprocessing, hingga pembangunan dan evaluasi model machine learning.

Materi kemudian berkembang pada teknik klasifikasi menggunakan Logistic Regression, Decision Tree, dan Random Forest, dilanjutkan dengan pembelajaran Unsupervised Learning melalui K-Means Clustering dan Hierarchical Clustering, serta Association Rule Mining menggunakan algoritma Apriori. Pada pertemuan terakhir, saya mulai mengenal konsep dasar Deep Learning menggunakan Artificial Neural Network (ANN) serta Natural Language Processing (NLP) melalui metode TF-IDF untuk analisis sentimen sederhana.

Melalui rangkaian praktikum ini, saya memahami bahwa keberhasilan sebuah proyek Data Science tidak hanya ditentukan oleh model yang digunakan, tetapi juga oleh kualitas data, proses analisis, evaluasi model, serta kemampuan menginterpretasikan hasil untuk menghasilkan informasi yang bermanfaat dalam pengambilan keputusan.
